# Predictive Customer Churn Modeling Project

## Project Overview
This project focuses on predictive modeling and risk scoring to understand bank customer churn and identify factors that influence customer retention.

## Project Objectives
- Analyze bank customer data.
- Identify customer churn patterns.
- Understand factors influencing customer retention.
- Develop insights to support customer retention strategies.
- Present findings through interactive dashboards.

## Tools Used
- Microsoft Excel
- Microsoft Power BI
- GitHub
